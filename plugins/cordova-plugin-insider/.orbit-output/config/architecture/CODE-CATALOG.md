# 📚 Code Catalog — cordova-plugin-insider

> Auto-generated by orbit init. Standalone reference; links back to [ARCHITECTURE.md](./ARCHITECTURE.md).

This plugin is a **three-layer Cordova bridge**: a JavaScript API layer (`js/`) that marshals calls over `cordova.exec` into native Android (Java) and iOS (Objective-C) implementations that wrap the Insider native SDKs.

```
JS app → js/ (bridge wrapper) → cordova.exec → src/android (Java) / src/ios (ObjC) → Insider native SDK
                                      ↑ Promise                ↓ cordova.fireDocumentEvent (callbacks)
```

### Fluent model/builder classes
- **`User.js`** — user profile. Chainable setters (`setName`, `setEmail`, `setBirthday`, `setAge`, opt-ins, `setCustomAttributeWith{String,Int,Double,Boolean,Date,Array}`, `unsetCustomAttribute`) all `return this`. `login`/`logout`/`logoutResettingInsiderID` support optional `insiderIDResult` callback. Dates → epoch-ms string.
- **`Product.js`** — product model. Splits state into `requiredFields` (constructor: product_id, name, taxonomy, image_url, unit_price, currency), `optionalFields` (color, size, brand `brnd`, sku, etc. — short server keys via `Constants`), and `customParameters[]` (typed). Chainable.
- **`Event.js`** — event builder. `addParameterWith{String,Int,Double,Boolean,Date,Array,StringArray,NumericArray}` push typed entries; `build()` dispatches `TAG_EVENT`.
- **`Identifier.js`** — identity builder for login. `addEmail`/`addPhoneNumber`/`addUserID`/`addCustomIdentifier`; `getIdentifiers()`.

### App Cards module
- **`InsiderAppCards.js`** — `Object.freeze`d namespace. `getCampaigns`, `markAsRead`, `markAsUnread`, `view`, `click`, `clickButton`, `delete`. Modern Promise + optional completion-callback style via `resolveWithCallback`; argument validation throws typed errors.
- **`InsiderAppCard.js`** — `InsiderAppCardsCampaignResponse`, `InsiderAppCard`, `InsiderAppCardButton` models.
- **`InsiderAppCardsError.js`** — `InsiderAppCardsError` + `InsiderAppCardsErrorCode`; `.from(error)` normalizes bridge errors.

### Events module
- **`InsiderEvents.js`** — `Object.freeze`d namespace observing SDK-recorded events. `addObserver(cb)` returns a `{ remove() }` subscription; there is no bulk teardown by design. Registers **at most one** native observer per process (via `Utils.streamExec`) and fans events out to a `Map`-backed subscriber registry; the last subscriber to leave triggers `removeEventObserver`. The callback is invoked as `(name, parameters, timestamp)` — matching the native `onEventRecorded` signature and the React Native / Flutter wrappers — where **`timestamp` is in whole SECONDS** (passed through from native unchanged — `new Date(ts * 1000)` is required).

### Enums / constants
- **`Constants.js`** — central registry of native reference strings, product server keys, platform ids (`android`/`ios`), and `SDK_VERSION` (`CDV-<version>`).
- **`Gender.js`**, **`CallbackType.js`**, **`CloseButtonPosition.js`**, **`ContentOptimizerDataType.js`** — value enums (each paired with a `types/*.d.ts`).

## 🟫 Native Layer — Android (`src/android/`)

- **`InsiderPlugin.java`** (`com.useinsider.cordova`, extends `CordovaPlugin`) — dispatches via `execute(action, args, callbackContext)`. Wraps `com.useinsider:insider` + `insiderhybrid`. Registers `InsiderCallback`, sets SDK type `"cordova"`, pushes callbacks to JS through `webView.loadUrl("javascript:cordova.fireDocumentEvent(...)")`. Uses Jackson `ObjectMapper` for (de)serialization.
- **`CDVUtils.java`** — helpers (JSON ↔ native model mapping). `convertMapToJSON` structurally converts an SDK `Map<String,Object>` (nested maps, iterables, Java arrays, `Date`, boxed numbers, null → `JSONObject.NULL`) into a `JSONObject` — never string interpolation, since event parameter values are integrator-supplied.
- **`Constants.java`** — Android-side reference constants.
- **`build-extras.gradle`** — native SDK pins (`com.useinsider:insider:16.0.1`, `insiderhybrid:1.3.4`), AndroidX, Firebase Messaging, Play Services Location, Huawei HMS, Jackson; compile/min/target SDK.

## 🟫 Native Layer — iOS (`src/ios/`)

- **`InsiderPlugin.m/.h`** (extends `CDVPlugin`) — `CDVInvokedUrlCommand` selectors (`init`, `initWithLaunchOptions`, `initWithCustomEndpoint`, `reinitWithPartnerName`, …). Wraps `InsiderMobile`. `registerCallback:` maps `InsiderCallbackType` → `cordova.fireDocumentEvent('ins_notification_handle', …)` via `commandDelegate evalJs`.
- **`CDVUtils.m/.h`** — helpers, success/error result senders.
- **`IDFAHelper.m/.h`** — IDFA collection support.
- Pods (in `plugin.xml`): `InsiderMobile 15.0.0`, `InsiderGeofence 1.2.4`, `InsiderHybrid 1.7.6`.
