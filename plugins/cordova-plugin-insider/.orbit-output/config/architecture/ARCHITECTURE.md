## 📦 Project Overview

**Name:** cordova-plugin-insider
**Version:** 4.0.1
**Team:** mobile.sdk
**Description:** Cordova plugin that bridges the Insider Mobile SDK (iOS & Android) into Cordova/hybrid applications through a JavaScript wrapper over `cordova.exec`. Published as an npm package; exposes the global `Insider` API.

**Type:** Single-service (one plugin package, native iOS + Android targets).

## 🧱 Layers

1. **JS bridge (`js/`)** — public API. Validates inputs, serializes objects to the typed bridge contract, calls native via `Utils.asyncExec`. Returns Promises.
2. **Native dispatcher (`src/android`, `src/ios`)** — receives actions, calls the Insider native SDK, returns results, and pushes callbacks back to JS via document events.
3. **Insider native SDK** — the actual platform SDK (not owned by this repo).

---

## 🔬 Design Patterns

- **Bridge** — JS ↔ native marshaling through the single `Utils.asyncExec` → `cordova.exec` path.
- **Facade / Singleton** — `InsiderPlugin` singleton presents one flat API over the native SDK.
- **Builder / Fluent API** — `User`, `Product`, `Event`, `Identifier` setters return `this`; `Event.build()` dispatches.
- **Type-tagged serialization** — `Utils.parseObjectWithTypes` converts JS values into `{key, type, value}` arrays the native side can decode deterministically.
- **Platform Strategy** — `cordova.platformId` branches select iOS- vs Android-specific native references; some methods are platform-only.
- **Frozen module** — `InsiderAppCards` is an `Object.freeze`d namespace with Promise + optional-callback ergonomics.

## 📐 Code Conventions

- **JS classes:** PascalCase; **methods:** camelCase.
- **Native references:** centralized as string constants in `js/Constants.js` (mirrored in `src/android` & `src/ios`).
- **Validation-first:** every public method calls `Utils.checkParameters([...])` and bails with `showParameterWarningLog` before any native call.
- **Error handling:** `try/catch` → `Utils.asyncExec(CLASS, PUT_ERROR_LOG, [generateJSONErrorString(error)])`.
- **Dates:** epoch-ms strings across the bridge (avoid timezone drift).
- **Booleans (consent/collection):** sent as lowercased strings.
- See [CODE-CATALOG.md](./CODE-CATALOG.md) for the full symbol catalog and the per-area `.claude/rules/` files for enforcement.

## 🔄 Data Flow

```
App calls Insider.itemPurchased(saleID, product, params)
  → checkParameters() validates
  → parseObjectWithTypes(params) → typed array
  → Utils.asyncExec("InsiderPlugin", "itemPurchased", [...]) → Promise
  → cordova.exec → native execute()/selector
  → Insider native SDK
Callbacks (notification open, insider id, foreground push):
  native → cordova.fireDocumentEvent('ins_*', data) → document.addEventListener in JS
```

## 🔢 Versioning

`SDK_VERSION` in `js/Constants.js` (`CDV-<version>`) is sent to native at init. On release, bump together:
- `package.json` `version`
- `js/Constants.js` `SDK_VERSION`
- `plugin.xml` `version` + iOS pod specs
- `src/android/build-extras.gradle` native pins
