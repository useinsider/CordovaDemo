# Prompts — cordova-plugin-insider

Reusable, context-aware AI prompts for working on this Cordova plugin. Generated by `orbit:prompt-generator` and tailored to this repo's architecture (`@.orbit-output/config/MASTER.md`, `@CODING.md`, `.claude/rules/`).

| Prompt | Use when you want to… |
|--------|------------------------|
| [code-new-bridge-method.md](./code-new-bridge-method.md) | Add a new public bridge API (JS + Android + iOS + types, with parity) |
| [test-jest.md](./test-jest.md) | Generate Jest unit tests for the JS bridge layer |
| [review-code.md](./review-code.md) | Review a change against this repo's standards |
| [debug-bridge.md](./debug-bridge.md) | Debug a JS↔native bridge / serialization / platform issue |

**How to use:** open a prompt, copy the `xml` block, fill the `{{placeholders}}`, and submit it to Claude Code (these are Claude-optimized). Each prompt lists the context files worth attaching.

Regenerate or add more with `/orbit:prompt-generator <task-type>` (types: code, review, test, refactor, debug, docs, explain, custom).
